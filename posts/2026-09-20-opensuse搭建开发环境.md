## 1. 前言

最近安装了opensuse leap 作为主力系统。作为一个有点系统洁癖的人，宿主机的干净可真是太重要了，把一切杂乱的东西都丢掉虚拟机里去。

## 2. 前期准备

安装必要软件

```bash
sudo zypper in distrobox podman
```

如果直接 `distrobox create dev`，`$HOME` 可能会被污染，所以要分离 `$HOME` 目录：

```bash
# 1. 在宿主机创建隔离的专用主目录，以及放代码的目录
mkdir -p ~/.local/share/distrobox-homes/pydev
mkdir -p ~/projects/python

# 2. 创建全新的 openSUSE Tumbleweed 容器
distrobox create \
  --name pydev \
  --image registry.opensuse.org/opensuse/tumbleweed:latest \
  --home ~/.local/share/distrobox-homes/pydev \
  --volume ~/projects/python:/workspace \
  -Y
```

**参数详解**：

- `--home ~/.local/share/distrobox-homes/pydev`：核心参数。容器内的用户家目录被隔离在这个文件夹里，宿主机真正的 `~` 目录不受丝毫影响。
- `--volume ~/projects/python:/workspace`：把宿主机的代码目录挂载到容器内的 `/workspace`。你在容器内写的代码保存在 `/workspace`，直接对应宿主机的 `~/projects/python`，既能用宿主机编辑器打开，又安全持久化。
- `-Y`：自动确认，安装必要的系统集成包。

**进入使用与后期彻底销毁**：

1. 进入全新隔离环境：`distrobox enter pydev`
2. 彻底销毁：`distrobox rm -f pydev`、`rm -rf ~/.local/share/distrobox-homes/pydev`

## 3. Python环境搭建

**进入虚拟机、更新源并安装开发必备工具**

```bash
distrobox enter pydev
sudo zypper refresh
sudo zypper install -y git which curl wget tar gcc gcc-c++ make python3-devel python3-pip
```

**配置包管理工具**

在 Linux 系统中，系统默认禁止直接在全局使用 `pip install`，必须在虚拟环境中安装依赖，这里使用 uv 来管理 Python 的虚拟环境和依赖。

在容器内执行：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc

# 验证安装：
uv --version
```

**创建工程**

在容器终端中，创建一个专门放 Python 学习代码的目录：

```bash
mkdir -p ~/projects/python-learn
cd ~/projects/python-learn

# 1. 创建虚拟环境
uv venv

# 2. 激活虚拟环境
source .venv/bin/activate

# 3. 安装学习必备利器：ipython 和 jupyterlab
uv pip install ipython jupyterlab rich

# 4. 进入交互式增强终端体验 Python
ipython
```

在 IPython 中输入 `print("Hello, openSUSE & Python!")` 即可开始你的第一行代码。
